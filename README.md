# Pylint and Flake8 Code Quality Repository

This repository contains reusable Pylint and Flake8 configuration files and scripts.

The purpose of this repository is to provide centralized code-quality checks that can be integrated into Jenkins CI/CD pipelines.

## Repository Structure

```text
pylint_flake8_int_jenkins/
│
├── .flake8
├── .pylintrc
│
├── requirements-quality.txt
│
├── scripts/
│   ├── run_flake8.sh
│   └── run_pylint.sh
│
└── README.md
